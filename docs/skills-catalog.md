# Каталог скиллов

Имя скилла совпадает с каталогом и с полем `name`. Загрузка в OpenCode — инструмент `skill`.

## Маршрутизатор

| Скилл | Кратко |
|---|---|
| `1c-config-router` | Определяет нужный workflow или скил для задачи |

|---|---|
| `1c-cf-init` | Создать пустую конфигурацию (scaffold XML), версии формата 2.17-2.21 |

| `1c-cf-validate` | Валидация конфигурации |

| `1c-cf-new-project` | Workflow: создать конфигурацию с нуля |
