Проверь уникальность UUID в файлах выгрузки 1С по пути из `$ARGUMENTS` или по текущему проекту.

Скрипт лежит рядом с этой командой: `check_uuid_duplicates.py`.
В репозитории набора это `commands/check_uuid_duplicates.py`.
После установки — `.opencode/commands/check_uuid_duplicates.py` или `~/.config/opencode/commands/check_uuid_duplicates.py`.
Запускай тот файл, который реально есть на диске.

## Аргументы

Пользователь может передать:

- путь к папке или файлу;
- `--fix`, чтобы заменить дубликаты;
- `--include-intra`, чтобы искать дубликаты внутри одного файла;
- пустую строку — тогда проверяй текущий каталог проекта.

## Выполнение

1. Если путь не передан, возьми `src/`, когда такой каталог есть, иначе текущий каталог.
2. Запусти:

```bash
python check_uuid_duplicates.py <аргументы>
```

На Windows, если `python` не находится, используй `py`.

3. Код 0 — дубликатов нет. Код 1 — покажи отчет и спроси, исправлять ли (`--fix`).
4. После `--fix` покажи, что изменилось. Если дубликаты остались, повтори `--fix` еще один раз: иногда нужно два прохода.
5. Не исправляй UUID в чужой выгрузке без согласия. Исправление меняет идентификаторы метаданных.
