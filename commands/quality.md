---
description: Сообщить, что снятие гейта качества хуком в OpenCode недоступно
---

Пользователь просит снять гейт качества или отдельную проверку.

Синтаксис из исходного набора:

```text
/quality release gate <причина> [--for 30m|2h|1d]
/quality release check <проверка@среда> <причина> [--for 30m|2h|1d]
```

В OpenCode эту запись сделать нельзя. Исходная команда ничего не выполняет сама: событие пишет хук `hooks/release-writer.mjs`, а каталога `hooks/` в этом репозитории нет. OpenCode не подхватывает хуки Claude Code.

Скажи это пользователю прямо. Не создавай файл следа, не правь конфигурацию и не имитируй снятие гейта. Если нужно запомнить исключение, предложи записать его вручную в файл проекта, который пользователь укажет.
