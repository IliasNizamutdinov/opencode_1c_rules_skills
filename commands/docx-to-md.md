---
description: Конвертировать DOCX в Markdown через pandoc, не зачитывая документ в контекст целиком
---

Конвертируй DOCX в Markdown. Путь к файлу — `$ARGUMENTS`. Если путь не передан, спроси его.

В исходном наборе команда вызывала `~/.claude/scripts/docx_to_md.py`. Этого скрипта в репозитории нет.
Не выдумывай его. Порядок такой:

1. Если у пользователя есть свой `docx_to_md.py` и он сам указал путь — запусти его.
2. Иначе проверь `pandoc`. Если его нет, остановись и скажи, что нужен pandoc. Не ставь пакеты без согласия.
3. Запусти из каталога документа:

```bash
pandoc "файл.docx" -t gfm -o "файл.md" --extract-media=images
```

4. Сообщи путь к `.md` и число картинок в `images/`. Содержимое документа в контекст не читай, если пользователь не просил разобрать текст.
5. Обратное направление, Markdown в DOCX по образцу, — скилл `docx-from-sample` или `md-to-docx`, не эта команда.
