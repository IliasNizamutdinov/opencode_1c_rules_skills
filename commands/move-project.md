---
description: Перенести каталог проекта на другой путь, не трогая базу сессий OpenCode
---

Перенеси каталог проекта. Источник и назначение берутся из `$ARGUMENTS`. Если аргументов нет, спроси оба пути.

Пример: `/move-project C:\Projects\my-app D:\Work\my-app`

## Файлы проекта

1. Проверь, что источник есть, а назначение свободно. Если назначение занято, остановись и спроси.
2. Перемести каталог. На Windows, если `mv` не может перейти между дисками, копируй через PowerShell и удаляй источник только после проверки копии и согласия пользователя:

```powershell
Copy-Item -Path '<source>' -Destination '<target>' -Recurse -Force
```

3. Не переноси `.env`, ключи и выгрузки с данными заказчика в чат. Они едут вместе с каталогом и в отчет не попадают.

## Сессии OpenCode

Сессии лежат не рядом с проектом. По документации OpenCode это каталог данных:

- Linux и macOS: `~/.local/share/opencode/`
- Windows: `%USERPROFILE%\.local\share\opencode`

Там база `opencode.db` (путь также показывает `opencode db path`) и снимки `snapshot/`. Записи привязаны к старому пути проекта.

Базу не редактируй и не копируй SQL-запросами. Поддерживаемого переноса истории на новый путь нет: в новом каталоге начни сессию заново. Скажи пользователю, что старая переписка осталась в базе и к новому пути сама не приклеится.

## Claude Code, только если им тоже пользуются

Память и jsonl-сессии Claude Code лежат в `~/.claude/projects/`. Имя папки нормализует путь: разделители, двоеточие и подчеркивание становятся дефисом. Не собирай имя вручную. Открой проект в Claude Code и возьми каталог, который клиент создал сам. Копируй `memory/`, `*.jsonl` и каталоги сессий только после согласия. Планы — `~/.claude/plans/<последний каталог пути>/`. После переноса попроси перезапустить клиент и не удаляй старые папки, пока пользователь не проверит, что память на месте.
