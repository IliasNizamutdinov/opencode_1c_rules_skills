# Правила и скиллы 1С для OpenCode

Набор для [OpenCode](https://opencode.ai/docs/): агент собирает и проверяет объекты 1С по формату выгрузки, а не поиском по чужим XML. Это адаптация [cursor-1c-skills](https://github.com/Desko77/cursor-1c-skills) (MIT). Исходные правила, скиллы и скрипты написаны Desko77 и участниками [cc-1c-skills](https://github.com/Nikolay-Shirokov/cc-1c-skills). Здесь изменены формат подключения, установщик и те инструкции, которые опирались на Cursor или Claude Code.

[Лицензия MIT](LICENSE)

## Что умеет набор

- Собрать объект метаданных, форму, роль, макет, схему компоновки, пакет XDTO, расширение, внешнюю обработку и отчет из понятного описания и разобрать их обратно.
- Проверить XML валидаторами набора без запущенной платформы: ссылки, пути формы, состав подсистемы, права, запросы, вызовы общих модулей.
- Держать стандарты BSL, антипаттерны, асинхронные методы, запросы, БСП, расширения и EDT в отдельных правилах. В ход попадает указатель, а не все тексты сразу.
- Поставить скиллы глобально или в один проект, не затирая ваши файлы.

Платформа нужна скиллам баз, бинарной сборки EPF/ERF и веб-публикации. Генерация XML и валидаторы обходятся без нее. EDT и MCP подключаются отдельно, скилл `ai-edt-tools` описывает плагин [AI-EDT](https://github.com/Desko77/ai-edt).

## Правила

В репозитории **49 правил**. Они лежат в `rules/` по разделам: `bsl`, `queries`, `performance`, `metadata`, `forms`, `extensions`, `bsp`, `skd`, `security`, `exchange`, `workflow`.

OpenCode 1 и OpenCode 2 загружают их через массив `instructions` в `opencode.json` и склеивают с `AGENTS.md`. В `opencode.jsonc` этого репозитория перечислен каждый из 49 файлов. После установки в проект те же пути указывают на `.opencode/1c-rules/`. Подробности и отличия версий — в [docs/installation.md](docs/installation.md).

Каталог с условиями чтения — [docs/rules-catalog.md](docs/rules-catalog.md).

## Скилы (121)

Скилл — каталог `skills/<имя>/SKILL.md`. Поле `name` совпадает с каталогом. OpenCode показывает описание и загружает тело инструментом `skill`, когда задача подходит.

## Требования

- OpenCode 1 или OpenCode 2.
- Windows: PowerShell 5.1+ для `install.ps1` и для `.ps1` скиллов.
- Linux и macOS: Bash для `install.sh`.
- Python 3.8+ — по желанию, для портов скриптов и части утилит.
- 1С 8.3, EDT, MCP, v8unpack, gcomp, Node.js — только для соответствующих скиллов. Таблица — в [docs/dependencies.md](docs/dependencies.md).

## Установка

Кратко. Подробно, включая проверку, обновление, удаление и ручное подключение через `opencode.json` — в [docs/installation.md](docs/installation.md).

Windows, глобально и в проект:

```powershell
git clone https://github.com/IliasNizamutdinov/opencode_1c_rules_skills.git C:\src\opencode_1c_rules_skills
Set-Location C:\src\opencode_1c_rules_skills
.\install.ps1 -Global
.\install.ps1 -ProjectDir C:\Projects\my-1c
.\install.ps1 -RulesOnly
.\install.ps1 -SkillsOnly
.\install.ps1 -Global -List
```

Linux и macOS:

```bash
git clone https://github.com/IliasNizamutdinov/opencode_1c_rules_skills.git ~/src/opencode_1c_rules_skills
cd ~/src/opencode_1c_rules_skills
./install.sh --global
./install.sh --project /path/to/my-1c
./install.sh --rules-only
./install.sh --skills-only
./install.sh --global --list
```

Повторный запуск обновляет набор. Файл, который отличается от версии репозитория, не перезаписывается, пока вы не подтвердите замену (`-Yes` или ответ в интерактиве). Перед заменой пишется резервная копия. Чужие скиллы не удаляются.

Удаление снимает только файлы, совпавшие с манифестом:

```powershell
.\install.ps1 -Uninstall
```

```bash
./install.sh --uninstall
```

## Пример

В проекте с выгрузкой конфигурации достаточно задачи обычными словами: «добавь справочник Контрагенты с ИНН и табличной частью контактных лиц». Агент загружает `1c-config-router`, затем `1c-meta-compile` и валидатор. Перед кодом модулей он читает `rules/bsl/1c-coding-standards.md` и `rules/performance/anti_patterns.md`.

Команда `/check-uuid` проверяет уникальность UUID. В этом репозитории она описана в `opencode.jsonc` и в `commands/check-uuid.md`. После установки в проект файл команды лежит в `.opencode/commands/`.

## Ограничения

- Все 49 правил перечислены в `instructions` и загружаются вместе с `AGENTS.md` в OpenCode 1 и OpenCode 2.
- Скиллы OpenCode 1 читает из `.opencode/skills` (в репозитории это ссылки на `skills/`). OpenCode 2 читает и этот каталог, и `skills` из `opencode.jsonc`. На Windows без `core.symlinks` ссылки могут стать текстовыми файлами: тогда поставьте набор скриптом, он копирует каталоги.
- Команда `/quality` не пишет след: хука из исходного набора в репозитории нет.
- Перенос сессий OpenCode при смене пути проекта не делается правкой `opencode.db`.
- `install.ps1` на Linux не запускался: в среде сборки нет PowerShell. На Windows прогоните `powershell -NoProfile -File .\install.ps1 -List`.
- Снапшот-тесты скриптов и работа платформы, EDT и MCP здесь не выполнялись.

Подробности — [docs/migration.md](docs/migration.md).
